# Agent Reliability Lab

A public-by-design engineering laboratory for durable agent execution, human approval, controlled tool effects and reproducible failure testing.

**Status: specification stage. No working runtime or achieved reliability measurements are claimed.** The repository is private pending implementation and final publication review.

The planned workflow resolves a synthetic delayed-delivery case using three sandbox tools. It will demonstrate persisted execution, worker crash recovery, approval enforcement, idempotent sandbox effects and separately labelled fixture/live evaluation.

- [Implementation specification](docs/SPECIFICATION.md)
- [Specification validation](docs/SPECIFICATION-VALIDATION.md)

Implementation begins with an executable runtime compatibility spike. Installation commands, examples and measured reports will be added when they actually work. Original products, customer data and credentials are excluded.

All project documentation is written in English. Public release requires a later explicit owner decision.
